## Pitfalls
- Memory loss in a consolidation pass happens before or at the write, so a document that re-renders clean proves nothing. The five reachable sites are `fitMemoryInput` head-and-tail clipping, `renderMemoryDocument` dropping whole entries over a section budget, the stored context sliced to `MAX_CONTEXT_CHARS` before the fit, `renderContextDocument` clipping its own sections, and `normalizeMemoryDocument` capping on write. `ConsolidateReport` carries the six loss counts plus `memoryWritten`/`contextWritten`, zeroed unless that artifact landed.
- `/memory update` can refuse for two unrelated reasons: the section budgets (`renderMemoryDocument` dropping whole entries → tier C `lossy-refused`, reported as `N section(s) exceeded their budget`) and the model output cap (`fitMemoryInput`'s `needed` grows with the document, and `adaptiveOutputTokens` clamps it against the model's own cap). Raising `maxMemoryChars` only aggravates the output half; the durable fix is shrinking the document.
- Gate numbers written down always expire: run `pnpm typecheck` / `pnpm build` / `pnpm test` and read pass and case counts, take `lib/client.js` size from build output, and expect 0 mutant markers in `lib/`. Historical mutation rounds are not enumerated.
- A document's own occupancy prose expires silently: re-measure per-section occupancy through the built renderer (`share-fit.mjs`), not `CONTEXT.md`'s written percentages, and expect tier C's whole-entry refusal one small growth away.
- The loaded-memory trap: `loadMemory` can return a document that already carries the truncation marker while the status object still reports `damaged: 0` and `poisoned: false`. The marker's `dropped` is normalized length minus kept prefix length, not original minus kept — never verify it by arithmetic and never grep for the marker.
- `tsc` emits tagged templates as `String.raw` followed by the template with a space, so `grep -cF` for an in-template marker returns 0 and looks like a failed restore or an empty mutant; locate mutants with `grep -n "<NAME> = "` in `lib/`.
- String counts taken from session logs are unusable because logs echo the agent's own command output, so `grep -c` mostly counts the probe itself; judge live behaviour through read-only interfaces (`cordis_inspect_query` `Config`/`Service`, projection caches) instead.
- `/handoff status` receipts do not self-identify: `threshold auto` and `context` are profile- and model-level numbers identical across workspaces, so any citation must carry workspace plus session id.
- An invalid mutant's red is not evidence — leaving a symbol unreferenced in `src/` makes `tsc` report `TS6133`, so keep every symbol referenced before judging red.
- Cross-repo transfer trap: dsh's finish reason is `max-tokens` while pi's is `length`, and copying pi's string silently disables the retry path.
- Pi triage passes: pi's prose about dsh is not trustworthy (it claimed nothing reads `handoffThinking`, which dsh did read) and its dead-symbol sweep would delete dsh's live `newestMemoryArchiveSync`. Detail: `docs/upstream-pi-triage.md`.
- pi batch I (loaded): the injected documents keep the policy sections inline and index the rest; an unnamed heading and a trailing `_[…]_` note stay inline, pointers are absolute, and the pointer language follows the document's own detector (`src/shared/language.ts`), so both tracked documents render Chinese pointers.
- pi batch J (loaded): the handoff summarizer is gone and `handoffThinking`/`/handoff thinking` retired hard-cut, so `/handoff now` needs no routed model while the auto path still resolves `contextWindow`. `isHandoffContinuationText` stays structural — a payload change must keep all six `<handoff>` closings matching or a seed counts as a human turn.
- The harness's subagent-list `activity` field means resident, not working: `list-children.ts` builds `childRow(…, 'running', …)` for every candidate `sessions.get(id)` still holds and only a cold read gives `'inactive'`, so judge live work with upstream's `list_agents`. `subagents.listChildren(parentId)` reads the parent-owned `subagent/catalog` projection instead (row shape differs by version; both carry `mode`).

- Cross-checking `.agents/memory/session-logs/INDEX.md` against the disk must parse each bullet's link target, never an id anywhere in the line: a session title can quote another session's id, so an anywhere-in-line match reports a false dangling entry and hides the real count.

Six faces move together: `config.ts`, `settings.ts`, `client/card-fields.ts`, `locales.ts`'s `field.*` keys, every reader and `settingPatch` write-back key, and tests.
- A render round-trip, not `isMemoryTruncated`, proves a hand-edited document is safe: the document cap can read `truncated:false` while one entry over `MAX_LIST_ITEM_CHARS` (800) is already queued for a silent clip. `CONTEXT.md` and `MEMORY.md` each need this check (`roundtrip.mjs` / `share-fit.mjs`): `itemTruncated 0`, no entry at the per-item cap, and a byte-identical round trip; split the long entry rather than dropping the fact.
- A context document can silently starve its own tail: `Open tasks` once sat at 99.7% of its share, so the next `/memory update` would have dropped whole trailing entries. Measure per-section occupancy after any large hand edit (`.agents/evidence/2026-10-07-context-section-balance/`) — the single-entry `roundtrip.mjs` does not see share drift.
- Hand-editing `CONTEXT.md` by appending plain text at the end of a section splices it into that section's last bullet and swallows the following heading, so `measure.mjs` reports a non-fixpoint (`stored` vs `rendered` diverge at the append point); write a new `- ` bullet per statement, and supply `options.updatedAt` when calling `renderContextDocument` directly or it throws `TypeError`.
- A load-state claim written down decays: a context bullet that says a batch is or is not live must be re-derived from the timestamp criterion and the probe, since the same file was read the opposite way on successive sessions and a stale `negative` line was copied into `CONTEXT.md` before a probe contradicted it.

- A learned body is pulled only when the model asks with `inspect_skill`, and a marked name whose body that round did not render is refused with `body not shown this pass` at the gate and at the write path. Briefs: `docs/batch-{g,h}-*.md`, `docs/vocabulary-conventions.md`.
- dsh ships machine-readable upgrade guides under `docs/upgrade-guide/` in the store repo — read them per version before reasoning about a delta, but a guide describes declared intent, so confirm the behaviour in the shipped `lib/`.
