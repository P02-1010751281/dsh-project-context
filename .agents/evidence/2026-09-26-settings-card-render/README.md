## 为什么这些像素属于**迁移后**的卡片，而不是被删掉的手抄卡片

三条独立判据，缺一不可：

1. 被删卡片 `git show 3ed2588^:client/settings-card.tsx` 里 `@deepseek-ai/dsh-client-ui-primitives`
   **出现 0 次**；当前卡片从该包导入（`client/settings-card.tsx:41`）并渲染 `<SettingsForm>`（`:261`）。
2. 服务端实际分发的 `lib/client.js` 内含 **1 处**平台 `require`（上一会话核对，sha256 与仓库产物一致）
   → 跑在浏览器里的就是迁移后的卡片。
3. 帧时间 **15:32:35/39** 晚于迁移构建（`3ed2588` 15:28:37、`8f247b8` 15:31:33）；此后客户端源码未再改动
   （`c8c8d79` 只动 test / docs / package.json）。

> 反例记录：文件大小**不是**页面分类器。15:29–15:31 那批 358830–383923 B 的帧是**别的会话的对话页**
> （`handoff · fcd247a8`，见 `99-*`），不是插件页。第一轮据此推测「疑似插件页」是错的；反过来说，
