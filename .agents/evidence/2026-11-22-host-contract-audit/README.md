## 1. Members and hidden dependencies

Scope: every property/method/index signature in the contract vs pinned `src/` outside host (entry points included, adapter hits separate). TypeScript 5.9.3 resolves access symbols, union arms, destructuring and contextual object literals, not spelling matches. Each row lists at most four examples per category. A union-tag access applies to the union; a contextual literal does not imply every union arm was constructed. This is not an interprocedural alias proof. Only direct `any` receiver reported: unrelated `left.localeCompare` in `skill-state-source.ts:64`.

* **No direct core reader:** `MessageBase.id`, `PluginTool.description`, `PluginTool.parameters`, `GenerateOptions.{provider,model,sessionId,messages,maxTokens,reasoningEffort,tools,signal}`. All constructed and sent; not dead requirements. `EventBase.surfaceOp` is directly read only by the adapter, for a decision invoked by the core. `RequestHeader.config.reasoningEffort` **is** read after a local cast in `parentModelSelection` (`project-handoff/child.ts:129–135`); dynamic projection lookup **is** used after a double cast in `projectTodoLines` (`project-memory/todo.ts:100–101`). The `ProjectionValues` string index itself is not required by that cast; only `todos` is consumed this way. Do not delete necessary producer members to satisfy the inaccurate “subset the cores read” description.
* **Missing live session member:** `Session.ownEvents()` — `ownEventsOf` (`project-handoff/guard.ts:75–77`) casts to an optional method and falls back to `snapshotEvents()`. The latter includes inherited history. rc.5 `core/session/lib/types/index.d.ts:232,239` distinguishes the two methods. A second adapter can conform and accidentally count an inherited turn. Model the capability and preserve/document the fallback.
* **Unmodeled payload read:** `session/title.data.title`, in `sessionTitleFromEntries` (`project-context/session-index.ts:98–108`), called with *live* `snapshotEvents()` at line 141 as well as imported archives. `session/session-title/lib/types/index.d.ts:36–42` adds this kind to the host map only when its declarations participate. Raw decoding is reasonable, but not evidence that the core never opens opaque payloads. `todos` is likewise an intentionally runtime-decoded projection: `todo.ts` reads item `content`/`status`. Separately, `archivedSectionFromLine` (`project-context/archive.ts:121–150`) reads `assistant/message.data.message.content` and `tool/result.data.message.content` from parsed JSON, not a live Host Session API; not counted as missing live members. Phase-2c registration args still come from Cordis, not this union.

## 4–5. Opaque evolution and adversarial controls

`types.ts:71–74` contains one `declare module` with **two interface augmentations**. Their keys are `Exclude<keyof ContentBlockMap,'text'|'tool-call'>` and `Exclude<keyof SessionEventMap,'user/message'>`; boolean marker values do not import payload shapes. The compiler sees the host maps augmented in the active program, not every plugin a deployed host might load. Adding a well-formed unused kind to either map adds a distinct opaque discriminant without consuming new payloads. Removing an unreferenced opaque kind drops the tag without leaving a stale literal; a typed comparison/registration referring to a removed kind can break (entry points compare `turn/end` and `step/start`, e.g. `project-handoff/index.ts:220–225`). String casts/raw reads may instead stop matching silently. Removing a **modeled** kind is different: the handwritten local arm persists; removal alone does not reliably trigger a diagnostic at an inbound-only seam. An upstream role-union extension is also outside these two registries.

Scratch-only controls on the pinned source:

1. Type-augment host `Session` with `auditOnlyExtra():number`, and the two maps with `audit/new-block`, `audit/new-event`; assign host Session to local Session and each literal to the respective opaque tag. `tsc -p rc5.json` **0**.
2. Append `export interface Session { readonly auditUnused?: number }` to scratch contract. [Usage scan](usage.cjs) produced `228 Session.auditUnused` with no reader/writer. This is a report row, not a nonzero-exit linter.
3. Baseline `node scripts/check-boundary.mjs`: **116 files / 0 failures**. Add a real type re-export from `@deepseek-ai/dsh-session` to scratch contract: **exit 1**, `FAIL single-door: src/host/contract.ts imports @deepseek-ai/dsh-session`; remove it: **exit 0** (117 files including scratch witness). Restored contract blob `f350a4af39a7ffb0671cda41d92e0051ce437cb1` equals pinned Git object.
